# Partner API: запуск и эксплуатация (для команды FundingPro)

Документ для владельца продукта и команды. Партнёру отправляются остальные файлы этой папки, этот файл не отправляется.

## Что уже сделано в коде

* Партнёрский API: `/v1/health`, `/v1/grants`, `/v1/grants/search`, `/v1/grants/{id}`, `/v1/leads`, `/v1/events`, `/v1/meta`.
* API-ключи `fp_live_…` / `fp_test_…`. В базе хранится только хеш. Ключ можно отозвать, у него есть срок действия, тестовый ключ не работает на production.
* Лимиты 60 запросов в минуту и 5 000 в месяц, не больше 50 записей на страницу и не больше 20 страниц.
* Журнал запросов без ключей и персональных данных, хранится 90 дней.
* Лиды: согласие обязательно; дубли за 30 дней склеиваются; есть `Idempotency-Key`; при каждом лиде приходит письмо менеджеру с замаскированными контактами.
* Админка `/admin/partners`: партнёры, ключи, лиды, оплаты, комиссии 10% (только после фактической оплаты), отчёт за месяц, публикация грантов, удаление данных по запросу.
* Партнёр видит только гранты, которые редактор **проверил и опубликовал** (вкладка «Публикация грантов»).
* Дополнительно закрыта массовая выгрузка через открытый каталог сайта: лимит 120 запросов в минуту с одного IP и не больше 50 записей на страницу.

## Шаги запуска (по порядку)

### 1. Production-база (Convex)
```bash
cd fundingpro
npx convex deploy                      # применит новую схему (только добавления, данные не трогает)
npx convex run --prod partnerApi:backfillGrantPartnerFields '{}'   # slug + поисковый текст для старых грантов
```

### 2. Vercel (production-проект)
Переменные окружения: `PARTNER_API_ENV=production`, `PARTNER_LEADS_NOTIFY_EMAIL=<ваш e-mail>`.
Домены: добавить `api.fundingpro.uz` в тот же проект; DNS-запись CNAME `api` → `cname.vercel-dns.com`.

### 3. Sandbox
1. Создать **отдельный** Convex-проект или deployment, например `fundingpro-sandbox`.
2. `npx convex env set PARTNER_SANDBOX_DEPLOYMENT true` (только там!), затем `npx convex deploy`.
3. `npx convex run partnerAdmin:seedSandbox '{}'`: команда выведет тестовый ключ `fp_test_…` один раз.
4. Создать второй Vercel-проект из того же репозитория с доменом `sandbox-api.fundingpro.uz`, переменной `PARTNER_API_ENV=sandbox` и ключами sandbox-Convex.

### 4. Наполнить каталог для партнёра
В `/admin/partners` откройте вкладку «Публикация грантов». Для каждого гранта, актуального для бизнеса Джизака: сверить источник → «Источник проверен → опубликовать». Без этого партнёр получит пустой список.

### 5. Партнёр
1. Отправить партнёру папку `docs/partner-api/` (кроме этого файла) и sandbox-ключ.
2. Когда партнёр пройдёт чек-лист из `sandbox.md`: в `/admin/partners` создать партнёра `jizzakh_business_platform` (production), указать его домен и IP сервера, нажать «Выпустить ключ» и передать ключ по защищённому каналу (не в Telegram-чат с историей).
3. Через 30 дней пилот закончится автоматически: API начнёт отвечать `PARTNER_SUSPENDED`. Чтобы продлить, измените срок пилота партнёра.

## Ежедневная работа

* Новый лид: приходит письмо → `/admin/partners` → «Лиды» → звонок в течение 24 часов → смена статуса.
* Клиент оплатил: «Отметить оплату», ввести фактическую сумму, например `10000000 UZS`. Комиссия 10% создаётся автоматически, только для первой оплаты.
* Выплатили комиссию партнёру: вкладка «Комиссии», статус `paid`.
* Партнёр нарушил условия: «Приостановить» (доступ закрывается сразу) или «Отозвать» ключ.
* Пользователь просит удалить данные: обезличивание по телефону или e-mail (`anonymize_leads` в API админки).

## Открытые вопросы, которые решает владелец

1. **Хранение персональных данных в РУз** (ст. 27¹ Закона о ПДн): нужна консультация юриста **до production-запуска**. Код позволяет вынести хранение лидов отдельно.
2. Кто отвечает за звонки лидам и в какой срок (SLA).
3. Коммерческие условия после пилота: меняются в настройках партнёра, код менять не нужно.

## Что сознательно не сделано (вне рамок пилота)

AI-генерация заявок, внутренний скоринг, CRM-доступ, экспорт, изменение грантов через API, автоматическая привязка оплаты на сайте к лиду: в пилоте оплату отмечает менеджер, а cookie `fp_partner_ref` уже фиксирует источник перехода.
